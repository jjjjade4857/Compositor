# Compositor 简体中文版详细使用教程

适用版本：从 Releases 安装的 Compositor 中文版（基于官方 v1.6.6），macOS、Apple silicon。本文以简体中文补丁界面为准；不同窗口尺寸和后续版本的菜单排列可能略有差异。

## 1. 先认识工作区

- **中央画布**：显示当前合成图像。缩放、平移不改变图像像素；实际像素可用 `⌘1`，适配窗口用 `⌘0`。
- **左侧工具栏**：移动/变换、选框、套索、魔棒/对象选择、裁剪、画笔、修复、仿制、模糊/涂抹、渐变、形状、文字、吸管、抓手和缩放。
- **图层面板**：按从上到下显示图层；可隐藏、重命名、拖动排序、放入组、调不透明度和混合模式。点击图层缩略图/名称选择目标。
- **顶部工具选项**：随当前工具变化，例如画笔大小/硬度/不透明度，文字字体/字号/对齐，形状颜色/圆角等。
- **底部状态提示**：说明当前工具可用的拖动、修饰键和确认/取消操作。
- **命令搜索**：`⌘F` 输入功能名称，选中后按 Return 执行；支持中文显示名，也可输入英文原名。

## 2. 建议的基本流程

### 新建画布

1. 按 `⌘N` 或“文件 → 新建画布”。
2. 设定宽、高和背景（透明或指定颜色）。常见网络图像可用 1920×1080；印刷版面请按成品尺寸与输出分辨率规划。
3. 确认创建后先按 `⌘⇧S` 另存为 `.comp` 工程。工程是可继续编辑的原生项目包。

### 导入照片或素材

1. 打开工程后选“文件 → 导入”，或把图片拖入窗口。
2. 支持常见 JPEG、PNG、GIF、HEIC/HEIF、TIFF、WebP、PDF、SVG、相机 RAW，以及 PSD/PSB。
3. PDF 多页会拆成图层；GIF 可带时间轴；RAW 会先进入显影调整流程。SVG/PDF 导入后转为像素，不再是可编辑矢量。
4. 导入后检查图层位置、尺寸和图层面板；大尺寸文档受设备内存预算限制。

### 排列与变换图层

1. 选左侧移动/变换工具（`V`），在画布拖动对象。
2. 拖动控制点缩放，旋转柄旋转；按住 `⌘` 拖控制点可自由扭曲，按 Shift 约束方向。
3. 选多个图层或一个组可共同变换；可在顶部数值栏精确输入位置、尺寸、比例和角度。
4. 移动时可开启吸附到画布、图层、参考线或网格。`⌘R` 显示标尺；从标尺向画布拖出参考线。
5. 变换尽量保持非破坏性；需要最终像素输出时再导出扁平图。

### 选区、抠图与蒙版

1. `M` 矩形/椭圆选框；`L` 自由/多边形套索；`W` 魔棒/对象选择（Tab 切换）。
2. Shift 添加选区，Option 减去选区；按住 Shift 拖可约束正方形/圆形。`⌘D` 取消选区，`⌘⇧I` 反选。
3. 魔棒按相近颜色选取；对象模式点击物体轮廓。也可以使用“选择主体”。
4. 在图层面板添加图层蒙版，白色显示、黑色隐藏、灰色半透明。可在蒙版上画、填充、反相、模糊和羽化；链接可控制蒙版是否随图层移动。
5. 剪贴蒙版让上方图层受下方基底透明区域约束。调整层/滤镜层可用于非破坏性调色与模糊。

### 绘画、修图与图形文字

- **画笔 `B` / 橡皮 `E`**：拖动绘画或擦除；`[` `]` 调大小，`⇧[` `⇧]` 调硬度；`1`–`0` 调不透明度（两位数字可输入精确百分比）。Shift 拖画直线。数位板支持压力控制。
- **污点修复 `J`**：在瑕疵上涂抹进行内容感知修复。
- **仿制图章 `S`**：Option-点击设置采样源，再拖动仿制；可选当前图层或合并采样。
- **模糊/涂抹 `R`**：切换模式后拖动处理像素或蒙版。
- **渐变 `G`**：拖动设定方向和范围，拖端点微调；Return 应用，Esc 取消。
- **形状 `U`**：新建可编辑矩形、圆角矩形、椭圆或线；Shift 约束比例，Option 从中心绘制；Shift-U 或 Tab 切换形状类型。
- **文字 `T`**：拖出段落框并输入；顶部设置字体、大小、颜色、对齐和字距。`⌘Return` 完成编辑，Esc 取消。字体在别的 Mac 上缺失时会替换。
- **吸管 `I`**：从画布取色；`X` 交换前景/背景色，`D` 重置为默认黑白。

### 调色、滤镜与效果

- 使用“图像”菜单中的色阶、曲线、色相/饱和度、曝光、黑白、色彩平衡等调整，或建立调整图层便于回改。
- Camera Raw 面板提供光线、颜色、曲线、混色、色彩分级、细节、光学和几何校正等控制。
- “滤镜”提供高斯/动态/渐进模糊、噪点、辉光、暗角、RGB 分离、镜头效果、色调对比、镜头校正和移除背景等。
- `⌃⌘F` 重复上次滤镜及其参数。滤镜层可保持可调；直接像素滤镜可能改变像素。
- 图层样式（描边、投影、颜色叠加、内阴影、外发光、内发光）可以后续编辑。

### 图层组织与合成

- 拖动图层可调整前后顺序；拖入文件夹可嵌套。Option-拖动复制。
- `⌘G` 编组；`⇧⌘G` 取消编组；`⌘J` 复制图层（有选区时可复制选区像素到新层）；`⌘E` 合并图层。
- 图层混合模式和不透明度位于图层面板上方。混合模式显示为中文，如“正片叠底”，底层工程值仍按 Compositor/英文枚举保存。
- “复制合并” `⇧⌘C` 复制当前可见合成结果。

### 保存、导出与尺寸

1. `⌘S` 保存 `.comp` 工程；`⌘⇧S` 另存为。工程包保留图层、蒙版和可编辑属性。
2. 分享静态成品用 `⇧⌘E` 导出 PNG；`⌥⇧⌘S` 直接打开 JPEG 导出；`⌥⇧⌘W` 打开“导出为”。
3. “导出为”可选 PNG、JPEG、TIFF、PDF、GIF、EXR（仅 HDR 内容提供）及通道打包 PNG。可预览、调整尺寸/JPEG 质量；JPEG/PDF 不保留透明背景。
4. “画布大小”改变画布边界；“图像大小”重采样整个文档像素。两者用途不同，重采样前建议保存副本。
5. 输出前检查像素尺寸、透明区域、色彩外观和目标格式。导出的扁平图是成品，不包含可编辑图层。

## 4. 与 Photoshop 的互通

### 可用的互通方式

- **导入 PSD/PSB**：通过“文件 → 打开/导入”选择 Photoshop 文档。当前读取器只支持 8-bit、RGB 或 CMYK 的 PSD/PSB；CMYK 文件会按嵌入配置转换到 RGB 工作空间。高位深、Lab/索引色等模式不在当前 PSD 导入支持范围内。
- **部分图层可编辑保留**：普通像素层、图层/组可见性、不透明度、已支持的混合模式、部分蒙版、剪贴关系，以及简单水平文字/矩形或椭圆形状会尝试映射成 Compositor 图层。导入前会出现转换报告，确认前可取消。
- **导出中间格式再进 Photoshop**：可扁平导出 PNG、JPEG、TIFF、PDF；有动画时间轴可导 GIF。PNG/TIFF适合透明成品，中间交换也可以用 TIFF；JPEG 是有损且不带透明通道。Compositor 没有 PSD/PSB 图层导出。
- **像素尺寸/分辨率**：PSD 导入会读取画布尺寸和分辨率元数据；Compositor 的工作色彩空间为 sRGB。可在导出前检查/调整图像尺寸与分辨率。
- **工程可持续往返的方案**：保留 Photoshop 原始 PSD；在 Compositor 做影像合成/修整，另存 `.comp` 工程用于继续编辑，并导出 TIFF/PNG 成品回 Photoshop。PSD 源文件不会被 Compositor 原位改写。

### 导入时常见转换或损失

| Photoshop 内容 | Compositor 中的处理 |
|---|---|
| 常规像素图层、图层位置/大小 | 尽量保留为可编辑像素图层 |
| 图层组 | 尽量转换为文件夹；组混合模式不支持时按穿透/普通组处理 |
| 图层蒙版 | 支持部分普通灰度蒙版；不能转换的蒙版会在报告中提示并跳过 |
| 剪贴蒙版 | 在基底层受支持时尝试转换；不支持会提示跳过 |
| 常用混合模式 | 已知模式映射；不支持的模式退回“正常”并报告 |
| 简单水平文字 | 有时可保留为可编辑文字；字体缺失会替换。其他文字会栅格化 |
| 智能对象 | 栅格化，链接内容不能再作为智能对象编辑 |
| 图层效果 | 可能丢弃，视觉效果会有差异 |
| 复杂矢量、路径或形状 | 多数栅格化；仅部分简单形状可编辑保留 |
| 调整图层 | 部分类型可能读取，但参数效果未必与 Photoshop 完全一致；未知类型跳过 |
| Photoshop 专有/未知图层类型 | 通常作为像素导入，或忽略不支持内容；查看转换报告 |
| PSD/PSB 导出 | 当前不支持；不能从 Compositor 写回带图层的 PSD/PSB |

### 推荐互通步骤

1. 在 Photoshop 先保存一份原始 PSD/PSB 副本；若有智能对象、复杂效果或特殊色彩模式，另导出一个合并预览图作对照。
2. 用 Compositor 打开副本，仔细阅读转换报告；取消后可回 Photoshop 简化复杂功能或改导 TIFF/PNG。
3. 确认画布尺寸、图层顺序、混合模式、蒙版与文字，再保存成 `.comp`，不要覆盖 PSD。
4. 在 Compositor 完成修改后导出 PNG/TIFF；在 Photoshop 新建文档或置入该导出文件继续排版/印前处理。
5. 需要交付可编辑 PSD 时，在 Photoshop 中将导出的合成图放入原 PSD，或在 Photoshop 内重建图层结构。Compositor 当前不能替代这一步。

## 5. 建议与限制

- 将 `.comp` 作为 Compositor 原生工作文件；PNG/JPEG/TIFF/PDF/GIF/EXR 是输出或交换图，不是带全部编辑历史的工程。
- PSD 兼容属于导入转换，不是完整双向兼容。高阶 Photoshop 项目先在副本上试开，并仔细核对导入报告。
- 中文版基于 v1.6.6 非官方源码构建，关闭了官方自动更新；教程和快捷键对应此版本。新版已更新至 v1.6.6；快捷键、导入器或菜单可能随上游版本改变。
- 原版仍保留在“应用程序”中；若遇到汉化显示问题，可用英文原版打开同一个 `.comp` 项目。
